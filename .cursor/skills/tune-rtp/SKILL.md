# Настройка RTP слота

Цель: RTP в диапазоне 94–96%. Проверяет только скрипт — не считай вероятности вручную.

## Скрипт

```bash
cd server && npm run rtp -- <slug> [спинов]
```

По умолчанию `neon-fruits` и 1 000 000 спинов. Выводит точный RTP (перебор всех комбинаций), RTP по симуляции, частоту выигрыша, долю возвратов 1× и максимальный множитель. Код выхода 1, если RTP вне диапазона.

Если tsx падает с `listen EPERM ... .pipe`, запусти команду без песочницы.

## Порядок работы

1. Запусти скрипт и зафиксируй текущие цифры.
2. Меняй только `*_WEIGHTS` и таблицы выплат в `server/src/games/<slug>.ts`. Логику `payout` и `spinReels` не трогай без явной просьбы.
3. Запускай скрипт после каждой правки, пока RTP не попадёт в диапазон.
4. Проверь, что точный RTP и симуляция расходятся не больше чем на 0,5 п.п. Если больше — ошибка в скрипте или в игре, разберись до коммита.
5. Покажи пользователю таблицу «было / стало» по всем метрикам.

## Ориентиры для хорошей игры

- Доля возвратов 1× — не больше трети от частоты выигрыша, иначе «выигрыши» в основном фальшивые.
- Частота выигрыша 25–40%.
- Максимальный множитель заметно выше остальных (джекпот-символ), но его вклад в RTP небольшой.

## Новая игра

Добавь её в объект `games` в `server/scripts/rtp.ts`: символы, веса, число барабанов, `payout`, `spin`. Экспортируй веса из файла игры как `<GAME>_WEIGHTS`.
