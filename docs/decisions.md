# Журнал решений

Что решено и почему. Новое решение — новая запись сверху. Отменённое не удаляем,
а помечаем «отменено» со ссылкой на запись, которая его заменила.

Формат: дата, решение, почему, что из этого следует.

---

### 2026-10-01 — Прод — один процесс

**Решение:** `npm start` поднимает один Node-процесс: Angular отдаёт страницы, `/api` обслуживает тот же Express-роутер. В разработке по-прежнему два процесса. В проде CORS выключен, cookie `secure`, процесс закрывает MongoDB по SIGTERM.
**Почему:** на хостинге один домен и один порт, а локально удобнее отдельный `ng serve`.

### 2026-10-01 — CI не пишет в живую базу

**Решение:** GitHub Actions собирает проект, считает RTP и запускает `npm test` без базы. Тесты, которые пишут в Atlas, остаются командой `npm run test:db` и запускаются вручную перед мержем. Новые имена с префиксом `probe_` регистрация не принимает.
**Почему:** база одна для прода и разработки, а секрет со строкой подключения в GitHub не нужен автоматическим проверкам.
**Следствие:** после мержа секрет `MONGODB_URI` в GitHub можно удалить. Защита `main` включается, когда этот workflow уже на `main`.

### 2026-10-01 — 50 спинов без аккаунта

**Решение:** без входа доступно 50 спинов со ставкой 10. У каждой игры свой счёт коинов. При входе или регистрации эти счета один раз складываются в баланс аккаунта, гостевая сессия закрывается, неиспользованные спины пропадают. С одного IP — пять новых проб за киевские сутки.
**Почему:** игру можно попробовать до регистрации, а после входа не должно быть отдельного кошелька на каждую игру.
**Следствие:** исход и баланс по-прежнему считает только сервер. Повторный вход не прибавляет те же коины второй раз.

### 2026-10-01 — Документация для агентов

**Решение:** входная точка `AGENTS.md`, устройство кода — `docs/architecture.md`, решения — этот файл.
Документация обновляется в том же PR, что и код.
**Почему:** несколько чатов работают параллельно, новый агент должен войти в контекст без пересказа.

### 2026-10-01 — Роадмап и цель запуска 6 ноября 2026

**Решение:** сроки и статусы — в `docs/roadmap.md`; правило «успеваем ли» и порядок урезания объёма — там же.
**Почему:** видеть, на каком мы этапе, и решать заранее, что режем при отставании.

### 2026-10-01 — Почта поддержки закрытая

**Решение:** адрес только в `server/.env` (`SUPPORT_EMAIL`). Игроки пишут через формы, сервер пересылает.
**Почему:** репозиторий публичный, адрес на сайте собирает спам.
**Следствие:** автор коммитов в git — тот же адрес; для новых коммитов нужен noreply-адрес GitHub.

### 2026-10-01 — К запуску обязательны аналитика, поддержка и отзывы

**Решение:** без них в прод не выходим. Аналитика своя, в MongoDB, без сторонних трекеров.
**Почему:** нужно видеть удержание и слышать игроков с первого дня; свои события не требуют
cookie-баннера и не передают данные третьим лицам.

### 2026-10-01 — Ресурсы только свои или под разрешённой лицензией

**Решение:** список разрешённых и запрещённых лицензий — в конституции, учёт — в `docs/assets.md`.
Некоммерческие лицензии (CC BY-NC) тоже запрещены.
**Почему:** исключить претензии правообладателей и не менять ресурсы, если позже появится монетизация.

### 2026-10-01 — Запуск полностью некоммерческий

**Решение:** нет платежей, покупки коинов, рекламы, донатов, партнёрок и спонсорских призов.
**Почему:** без ставки, которая чего-то стоит, и без выигрыша с ценностью продукт по ключевым признакам
не азартная игра. Основные юридические вопросы при этом отпадают; остаются персональные данные,
соглашение, права на контент, 18+.
**Следствие:** любая монетизация — только после отдельного решения и консультации юриста.

### 2026-10-01 — Одна база для прода и разработки

**Решение:** один кластер и одна база Atlas.
**Почему:** решение владельца — проще и дешевле.
**Следствие:** тесты и скрипты пишут только в пользователей `probe_` и удаляют их за собой; к запуску —
платный уровень с бэкапами; отдельного стейджинга с другими данными нет.

### 2026-10-01 — RTP слотов 94–96%

**Решение:** целевой RTP 94–96%, проверка скриптом `rtp.ts`, который падает вне диапазона.
**Почему:** при 79% игроки быстро теряли коины; возвраты ставки 1× выглядели как выигрыш, но им не были.

### 2026-09-30 — Игра, а не оператор азартных игр

**Решение:** social casino на коины без денежной ценности, без вывода и обмена.
**Отклонено:** настоящее онлайн-казино без лицензии PlayCity; работа через крипту, зарубежную компанию
или чужую лицензию (например, Кюрасао); американская схема sweepstakes; переименование ставок в коины;
лотерея; работа внутри чужой лицензии.
**Почему:** бюджета на лицензию оператора нет, а обходные схемы для Украины — нелегальная деятельность.

### 2026-09-30 — Сервер решает исход, баланс меняется атомарно

**Решение:** исход спина и выплаты считаются только на сервере через `crypto.randomInt`; баланс меняется
одной операцией с условием в фильтре, в транзакции с записью в журнал.
**Почему:** клиенту нельзя доверять; параллельные запросы не должны уводить баланс в минус.

### 2026-09-30 — Стек и база

**Решение:** Angular с пререндером публичных страниц ради SEO, Express 5, Mongoose, MongoDB Atlas.
Локальный `mongod` не используется.
**Почему:** выбор владельца; удалённый кластер одинаков для всех окружений.

### 2026-09-30 — Вход по логину и паролю, без почты

**Решение:** регистрация только с логином и паролем.
**Почему:** минимум персональных данных.
**Следствие:** восстановить доступ через почту нельзя; предложен код восстановления (задача 3.8, не решено).
